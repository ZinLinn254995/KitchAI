# Roadmap

This is a provisional sequence of broad project phases, not an approved
delivery schedule or a detailed task plan. Scope and order may change after
owner review. Only work entered in the [task registry](TASK_REGISTRY.md) is an
active task.

## Provisional Phases

| Phase | Theme | Status |
| --- | --- | --- |
| P0 | Project and documentation foundation | In progress |
| P1 | Core business data: ingredients, menus, and recipes | Provisional |
| P2 | Purchasing and actual cost tracking | Provisional |
| P3 | Sales, expenses, and business/personal finance records | Provisional |
| P4 | AI assistant | Provisional |
| P5 | PWA, synchronization, sign-in, hosting, and external integrations | Provisional |

No phase beyond the current foundation is broken into coding tasks here. Product
priorities, phase boundaries, and dependencies remain to be confirmed. See
[unresolved questions](DECISIONS.md#unresolved-questions).
